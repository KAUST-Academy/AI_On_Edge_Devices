% Goal and plan of the Day 7 lab.

\begin{frame}{Goal of this lab}
  \begin{itemize}
    \item \textbf{Goal:} your group has a runtime comparison on the
          Raspberry Pi 5: the latency of one model for each runtime, thread
          count, and precision.
    \item \textbf{Board:} the Raspberry Pi 5 with the camera.
    \item \textbf{Deliverable:} the latency table and the Decision Log in
          the file \code{report.md}.
  \end{itemize}
  \vskip 0.4em
  \begin{block}{From the lecture to the lab}
    The lecture gave the reasons: SIMD kernels, threads, the three layers of
    a runtime, and the graph optimizer. All its numbers are from an x86
    processor. In the lab, you export the same model, you look at its
    graphs, and you measure it on the board.
  \end{block}
  \vskip 0.2em
  \keypoint{Predict each number before you measure it. A wrong prediction
    teaches more than a correct one.}
\end{frame}
