    \toprule
    \textbf{Problem} & \textbf{Fix or fallback} \\
    \midrule
    The name \code{pi-NN.local} does not work
      & Join the Wi-Fi \code{edgeai-lab}. Use the IP address that the
        instructor gives. \\
    \code{No module named 'ai\_edge\_litert'}
      & The environment is not active:
        \code{source \textasciitilde/tflite\_env/bin/activate} \\
    The camera gives no photo
      & Do Part B with the cat photo only. Tell the instructor. \\
    The board has no internet connection for the cat photo
      & Download the photo on the laptop and copy it with \code{scp}. \\
    The environment for the notebook does not install
      & Upgrade \code{pip} first. Install only \code{requirements.txt} in a
        new environment. Or work with a second group. \\
    A task is not complete in time
      & Use the file or the cell of the folder \code{solutions/}. Write
        this in the report. \\
    \code{pi/bench.py} prints \code{not found} for a file
      & Copy the file with the \code{scp} command of Part C. The instructor
        has the \code{float32} files. \\
    The latency changes much between two runs
      & Close the other programs. Read the temperature with
        \code{vcgencmd measure\_temp}, and wait for one minute. \\
    \bottomrule
  \end{tabular}
