% Learning outcomes of the module. Module TH-9 of Section 6.7 of the
% syllabus: "The machine learning paradigm". The syllabus gives no list of
% outcomes for this module, so the three outcomes come from its description.
\begin{frame}{Learning outcomes}
  After this module you can:
  \begin{itemize}
    \item Explain what changes when a program no longer holds the rules and
          a model holds them instead.
    \item Name the four parts of a learned model: features, labels, model,
          and loss, and say what each one is.
    \item Decide if a problem needs written rules or a learned model, and
          name the reason for the decision.
  \end{itemize}
\end{frame}
