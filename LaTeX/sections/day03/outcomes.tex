% Motivation and learning outcomes.
% The outcomes are the outcomes of Day 3 in the syllabus.
\begin{frame}{Why this day matters}
  \begin{itemize}
    \item A trained model is a file on a laptop. A microcontroller has no
          Python, no file system for the model, and no operating system.
    \item You must change the format of the model, and you need a runtime that
          fits in kilobytes of memory.
    \item In the lab you train a motion classifier on your Day 2 dataset,
          convert it, and run it on the XIAOML Kit.
    \item You measure the arena size, the flash use, and the latency. Day 4
          makes these three numbers smaller.
  \end{itemize}
\end{frame}

\begin{frame}{Learning outcomes}
  After this day you can:
  \begin{itemize}
    \item Explain the TensorFlow Lite Micro interpreter, the operator
          resolver, and the tensor arena.
    \item Convert a Keras model and a PyTorch model to the LiteRT format.
    \item Extract spectral features from a time series.
    \item Deploy a model on a microcontroller and measure arena size, flash
          use, and latency.
  \end{itemize}
\end{frame}
