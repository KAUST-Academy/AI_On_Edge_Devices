\begin{frame}{Decision Log}
  Write about 100 words. State one design decision, give your measured
  numbers, and name the trade-off.
  \vskip 0.4em
  \begin{exerciseblock}
    A farm wants an offline assistant on a Raspberry Pi 5 in a greenhouse.
    The workers type questions about the manual of the greenhouse
    controller. The first word of the answer must appear in less than 10
    seconds.
    \begin{itemize}
      \item Which model and which quantization level do you select?
      \item Which context and which k?
      \item Which part of the job does not need a language model?
    \end{itemize}
  \end{exerciseblock}
  \vskip 0.2em
  A good Decision Log:
  \begin{itemize}
    \item gives the rates of your board with their method, and the prompt
          tokens of one question,
    \item names the correct answers of your test, not only the valid ones,
    \item names what you lose: for example speed against correct facts.
  \end{itemize}
\end{frame}
