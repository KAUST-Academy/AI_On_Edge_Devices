    \code{the package ultralytics is not available}
      & The environment is not active:
        \code{source \textasciitilde/yolo/bin/activate} \\
    The camera gives no photo
      & Use \code{images/bus.jpg} in Part A, and \code{--source images/}
        in Parts C and D. Tell the instructor. \\
    The download of the dataset stops
      & Run \code{python get\_dataset.py} again. It keeps the complete
        images. \\
    The training is not complete in time
      & The instructor gives the file \code{cupbottle.pt}. Put it into
        \code{models/} and run the notebook from section 3. \\
    A task is not complete in time
      & Use the cell or the file of the folder \code{solutions/}. Write
        this in the report. \\
    The export to LiteRT stops with an error
      & Do Parts C and D with the two NCNN folders. The instructor gives
        the four LiteRT files. \\
    The live image has many wrong boxes
      & Use the image size of the file name: \code{cupbottle\_320...}
        runs with 320. \\
    The custom model does not find your objects
      & Use \code{--conf 0.15}, a plain background, and a distance of
        about 50 cm. \\
