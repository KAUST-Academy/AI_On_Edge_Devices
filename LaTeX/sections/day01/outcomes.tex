% Motivation and learning outcomes.
% The outcomes are the outcomes of Day 1 in the syllabus.
\begin{frame}{Why this day matters}
  \begin{itemize}
    \item A model that runs in the cloud does not always run on a small
          device. Memory, power, and latency set hard limits.
    \item You must know the limits of a device before you select a model
          for it.
    \item In the lab you set up the XIAOML Kit and test its sensors. Then
          you calculate if three models fit four devices.
    \item This day gives the terms and the budgets that all later days use.
  \end{itemize}
\end{frame}

\begin{frame}{Learning outcomes}
  After this day you can:
  \begin{itemize}
    \item Explain the four deployment paradigms and the constraints that
          separate them.
    \item Estimate the parameters, the operations, and the peak activation
          memory of a model.
    \item Decide from flash and RAM numbers if a model fits a device.
    \item Set up the toolchain and test each sensor of the XIAOML Kit.
  \end{itemize}
\end{frame}
