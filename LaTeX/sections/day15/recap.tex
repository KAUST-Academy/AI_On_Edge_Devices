% Recap of the day. Three to five points, then the one point to keep.
\begin{frame}{Recap}
  \begin{itemize}
    \item An edge AI system is a set of trade-offs: accuracy against memory,
          latency, energy, and cost. Each day of the course measured some of
          them.
    \item A design decision needs a measured number and a named trade-off.
          This is the method of the Decision Log.
    \item The capstone joins the parts of the course: a model on the XIAO, a
          model on the Raspberry Pi, MQTT messages, a local decision, and
          monitoring.
  \end{itemize}
  \vskip 0.5em
  \keypoint{Measure before you decide, and write the number next to the
            decision.}
\end{frame}
